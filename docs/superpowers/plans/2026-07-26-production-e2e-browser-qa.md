# Production E2E Browser QA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and run a production-grade E2E browser QA workflow for the deployed admin and card-issuer consoles, including temporary production test data, payment config restore, cleanup checks, screenshots, and product/engineering findings.

**Architecture:** Add a small QA harness that separates API orchestration from browser inspection. Python owns authentication, production data setup, cleanup, redaction, and report generation; a Node CDP helper owns real Chrome route sweeps and screenshots without adding Playwright or Puppeteer. Raw artifacts stay ignored under `qa-artifacts/`; only sanitized reports may be committed after review.

**Tech Stack:** Python 3, `requests`, local project `crypto.py`, Node.js built-in `fetch`/`WebSocket`, system Chrome via DevTools Protocol, existing FastAPI/Vue production deployment, GitHub Actions.

---

## Scope Check

This plan implements one workflow: production E2E QA after Pull Request `#1` is merged and deployed. It covers browser UI verification, admin/issuer data flows, cleanup, and reporting together because they must share the same test prefix, credentials, tokens, screenshots, and cleanup guard. It does not implement product fixes found by QA; those become follow-up plans after the report is reviewed.

## File Structure

- Modify `.gitignore`: ignore `qa-artifacts/` so screenshots, raw JSON, proof images, and token-bearing transient files are never committed.
- Create `scripts/production_e2e_browser_qa.py`: QA orchestrator. Responsibilities: read env vars, login with AES when available, call production APIs, create prefixed test data, restore payment config, cleanup, residue checks, redaction, write sanitized report.
- Create `scripts/browser_cdp_sweep.mjs`: browser route sweeper. Responsibilities: launch Chrome, inject authenticated localStorage from stdin, visit routes by role and viewport, capture screenshots, collect console errors, runtime exceptions, failed network requests, toast text, body text, and layout metrics.
- Create `tests/test_production_e2e_browser_qa.py`: unit tests for redaction, run prefix generation, cleanup guard, report safety, payment snapshot restore payload shape, and browser-result evaluation.
- Generated at runtime only: `qa-artifacts/<run_id>/raw/`, `qa-artifacts/<run_id>/screenshots/`, `qa-artifacts/<run_id>/production-e2e-browser-report.md`.

## Shared Environment Contract

Before running production QA, set these variables locally in the terminal. Do not paste their values into chat, docs, reports, command history screenshots, or Engramory.

PowerShell example:

```powershell
$env:LEMON_QA_BASE_URL = "http://154.12.26.231"
$env:LEMON_QA_ADMIN_USERNAME = Read-Host "Admin username"
$securePassword = Read-Host "Admin password" -AsSecureString
$passwordPtr = [Runtime.InteropServices.Marshal]::SecureStringToBSTR($securePassword)
try {
  $env:LEMON_QA_ADMIN_PASSWORD = [Runtime.InteropServices.Marshal]::PtrToStringBSTR($passwordPtr)
} finally {
  [Runtime.InteropServices.Marshal]::ZeroFreeBSTR($passwordPtr)
}
$env:LEMON_QA_CONFIRM_PRODUCTION = "I_UNDERSTAND_THIS_CREATES_TEMP_PRODUCTION_DATA"
```

Required safety rules:

- `LEMON_QA_BASE_URL` must be an explicit production URL, not empty.
- `LEMON_QA_CONFIRM_PRODUCTION` must match exactly before any write operation.
- Every created resource must use one run prefix generated by the script, for example `E2E_UI_QA_20260726_030000_`.
- The script must not print passwords, tokens, cookies, full card codes, server credentials, or complete device fingerprints.
- Cleanup must refuse to delete resources that do not start with the run prefix.

from __future__ import annotations

import copy
import json
import re
from dataclasses import dataclass, field
from datetime import datetime
from pathlib import Path
from typing import Any


SECRET_KEYS = {
    "authorization",
    "cookie",
    "password",
    "token",
    "access_token",
    "refresh_token",
    "secret",
    "app_secret",
}
FORBIDDEN_REPORT_MARKERS = ("token=", "password=", "cookie=", "Authorization:", "Bearer ")


class QASafetyError(RuntimeError):
    pass


def build_run_prefix(now: datetime | None = None) -> str:
    stamp = (now or datetime.now()).strftime("%Y%m%d_%H%M%S")
    return f"E2E_UI_QA_{stamp}_"


def is_owned_by_run(value: str | None, prefix: str) -> bool:
    return bool(value and value.startswith(prefix))


def assert_owned_by_run(value: str | None, prefix: str) -> None:
    if not is_owned_by_run(value, prefix):
        raise QASafetyError(f"Refusing cleanup for non-prefixed resource: {value!r}")


def mask_middle(value: str, keep: int = 3) -> str:
    if len(value) <= keep * 2:
        return "***"
    return f"{value[:keep]}***{value[-keep:]}"


def redact(value: Any) -> Any:
    if isinstance(value, dict):
        result = {}
        for key, item in value.items():
            lower = str(key).lower()
            if lower in SECRET_KEYS or lower.endswith("_token") or "password" in lower:
                result[key] = "<redacted>"
            elif lower in {"kami", "kami_code", "code", "device_fingerprint", "fingerprint"} and isinstance(item, str):
                result[key] = mask_middle(item)
            else:
                result[key] = redact(item)
        return result
    if isinstance(value, list):
        return [redact(item) for item in value]
    return copy.deepcopy(value)


def evaluate_browser_result(result: dict[str, Any]) -> list[dict[str, str]]:
    findings = []
    route = result.get("route", "<unknown>")
    if result.get("console_errors"):
        findings.append({"severity": "P0", "route": route, "message": "console.error captured"})
    if result.get("exceptions"):
        findings.append({"severity": "P0", "route": route, "message": "runtime exception captured"})
    if result.get("network_failures"):
        findings.append({"severity": "P1", "route": route, "message": "unexpected network failure captured"})
    layout = result.get("layout") or {}
    if layout.get("horizontal_overflow"):
        findings.append({"severity": "P2", "route": route, "message": "horizontal overflow detected"})
    if float(layout.get("large_blank_ratio") or 0) >= 0.55:
        findings.append({"severity": "P2", "route": route, "message": "large blank area detected"})
    if layout.get("overwide_cards"):
        findings.append({"severity": "P2", "route": route, "message": "overwide cards detected"})
    if int(result.get("body_text_length") or 0) < 40:
        findings.append({"severity": "P1", "route": route, "message": "page body text too short"})
    return findings


@dataclass
class QAReport:
    run_id: str
    artifact_dir: Path
    sections: list[tuple[str, list[str]]] = field(default_factory=list)

    def add_section(self, title: str, lines: list[str]) -> None:
        self.sections.append((title, lines))

    def render(self) -> str:
        parts = [f"# Production E2E Browser QA Report", "", f"Run ID: `{self.run_id}`", ""]
        for title, lines in self.sections:
            parts.extend([f"## {title}", ""])
            parts.extend(f"- {line}" for line in lines)
            parts.append("")
        return "\n".join(parts)

    def write(self) -> Path:
        content = self.render()
        for marker in FORBIDDEN_REPORT_MARKERS:
            if marker in content:
                raise QASafetyError(f"Report contains forbidden sensitive marker: {marker}")
        self.artifact_dir.mkdir(parents=True, exist_ok=True)
        path = self.artifact_dir / "production-e2e-browser-report.md"
        path.write_text(content, encoding="utf-8")
        return path


def main() -> int:
    print("Production E2E Browser QA harness skeleton. Use later tasks to add execution modes.")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

(() => {
  const viewportWidth = window.innerWidth;
  const viewportHeight = window.innerHeight;
  const body = document.body;
  const elements = Array.from(document.querySelectorAll('body *'));
  const rects = elements
    .map((el) => ({ el, rect: el.getBoundingClientRect() }))
    .filter(({ rect }) => rect.width > 0 && rect.height > 0 && rect.bottom >= 0 && rect.top <= viewportHeight);
  const horizontalOverflow = document.documentElement.scrollWidth > viewportWidth + 2;
  const overwideCards = rects
    .filter(({ el, rect }) => /card|panel|el-card/.test(el.className || '') && rect.width > viewportWidth * 0.92)
    .slice(0, 5)
    .map(({ el, rect }) => ({ className: String(el.className), width: Math.round(rect.width) }));
  const visibleArea = rects.reduce((sum, { rect }) => {
    const w = Math.max(0, Math.min(rect.right, viewportWidth) - Math.max(rect.left, 0));
    const h = Math.max(0, Math.min(rect.bottom, viewportHeight) - Math.max(rect.top, 0));
    return sum + Math.min(w * h, viewportWidth * viewportHeight);
  }, 0);
  const largeBlankRatio = Math.max(0, 1 - Math.min(1, visibleArea / (viewportWidth * viewportHeight * 1.8)));
  return {
    title: document.title,
    bodyTextLength: (body.innerText || '').trim().length,
    bodyTextSample: (body.innerText || '').trim().slice(0, 300),
    horizontalOverflow,
    overwideCards,
    largeBlankRatio: Number(largeBlankRatio.toFixed(2)),
    toastText: Array.from(document.querySelectorAll('.el-message, .el-notification')).map((el) => el.innerText.trim()).filter(Boolean),
  };
})()

import os
import requests
from dataclasses import dataclass


PRODUCTION_CONFIRMATION = "I_UNDERSTAND_THIS_CREATES_TEMP_PRODUCTION_DATA"


@dataclass
class QAConfig:
    base_url: str
    admin_username: str
    admin_password: str
    confirmation: str

    @classmethod
    def from_env(cls) -> "QAConfig":
        cfg = cls(
            base_url=os.getenv("LEMON_QA_BASE_URL", "").rstrip("/"),
            admin_username=os.getenv("LEMON_QA_ADMIN_USERNAME", ""),
            admin_password=os.getenv("LEMON_QA_ADMIN_PASSWORD", ""),
            confirmation=os.getenv("LEMON_QA_CONFIRM_PRODUCTION", ""),
        )
        if not cfg.base_url.startswith(("http://", "https://")):
            raise QASafetyError("LEMON_QA_BASE_URL must be an explicit http(s) URL")
        if not cfg.admin_username or not cfg.admin_password:
            raise QASafetyError("Admin username and password must be provided through environment variables")
        if cfg.confirmation != PRODUCTION_CONFIRMATION:
            raise QASafetyError("LEMON_QA_CONFIRM_PRODUCTION must confirm temporary production writes")
        return cfg


@dataclass
class AuthSession:
    token: str
    role: str
    user_info: dict[str, Any]

    def as_browser_storage(self) -> dict[str, Any]:
        return {"token": self.token, "role": self.role, "userInfo": self.user_info}


class APIClient:
    def __init__(self, base_url: str, auth: AuthSession | None = None):
        self.base_url = base_url.rstrip("/")
        self.auth = auth
        self.session = requests.Session()

    def request(self, method: str, path: str, **kwargs):
        headers = kwargs.pop("headers", {})
        if self.auth:
            headers["Authorization"] = f"Bearer {self.auth.token}"
        response = self.session.request(method, f"{self.base_url}{path}", headers=headers, timeout=30, **kwargs)
        return response

    def json(self, method: str, path: str, expected: tuple[int, ...] = (200,), **kwargs) -> dict[str, Any]:
        response = self.request(method, path, **kwargs)
        if response.status_code not in expected:
            raise QASafetyError(f"{method} {path} returned {response.status_code}: {response.text[:300]}")
        return response.json()


def login(base_url: str, username: str, password: str) -> AuthSession:
    client = APIClient(base_url)
    payload: dict[str, Any] = {"username": username, "password": password, "encrypted": False}
    key_response = client.request("GET", "/api/v1/auth/login/public-key")
    if key_response.status_code == 200:
        try:
            from crypto import CryptoHelper
            aes_key = key_response.json().get("aes_key")
            if aes_key:
                encrypted = CryptoHelper.aes_encrypt({"username": username, "password": password}, aes_key)
                payload = {**encrypted, "encrypted": True}
        except Exception:
            payload = {"username": username, "password": password, "encrypted": False}
    data = client.json("POST", "/api/v1/auth/login", json=payload)
    return AuthSession(token=data["token"], role=data["role"], user_info=data["user_info"])
```
